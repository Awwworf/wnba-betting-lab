# WNBA Betting Lab 🏀

Проект: разгон банка 30 → 10,000 USDT на ставках WNBA (Stake).
Старт: 06.08.2026, банк 30.00 USDT.

## Правила банкролла
- Одинар: 3-5% банка (сейчас 0.25-0.30 USDT)
- Дневной лимит: 15% банка
- Stop-loss дня: -10% банка
- Фавориты -14+ на серии 7+ побед: НЕ СТАВИМ
- H2H учитываем только в полных составах

## Роли
- Аналитик (AI): поиск +EV линий, пост-мортем, калибровка модели
- Риск-менеджер (я): финальное решение по размеру ставки
