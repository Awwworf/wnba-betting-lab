# Трекер отсутствующих (обновляется после каждого игрового дня)

Назначение: межматчевый контроль статусов игроков. Возврат стартера после
травмы = +EV-окно (рынок реагирует медленнее, чем должен).

## Легенда
- 🔴 DND / травма — проверять возврат перед следующим матчем
- 🟡 Inactive / личные / probable — проверять активацию
- ⚪ DNP (решение тренера) — стабильный скретч
- ⛔ OFS — вне сезона (не проверять)
- Кейс возврата: статус «не играл» → вышел в следующем матче

## Калибровка точности injury-отчётов (Rotowire/ESPN)
- OUT по звёздам и основной ротации: 10/10 точных → ДОВЕРЯЕМ
- OUT/GTD по игрокам скамейки (4-5 минут): врут и переворачиваются
  (Мэйр SEA 09.08, Лейте POR 09.08) → это ШУМ, ставки на этом НЕ строить
- GTD/questionable по звёздам: ненадёжны → ждём финальный отчёт + стартовые пятёрки
- Итоговая точность OUT-статусов: 10/12 (оба промаха — скамейка)

## Протокол применения (перед каждым матчем)
1. Поднять флаги обеих команд из трекера.
2. Получить свежий injury-отчёт + стартовые пятёрки.
3. Если 🔴-игрок вернулся и линия не сдвинута → +EV-сигнал.
4. Если 🔴-игрок из тройки-ядра (кейс LVA) сел → фейд или пропуск.
5. Статусы скамейки (шум) в расчёт НЕ брать.
