    - MIN 06.08 (31:51 лидерства → поражение).

### Ошибки в данных / ростеры
16. **Не доверять памяти о ростерах:** Грайнер и Бёрк в 2026 играют за CON (не PHO).
    - Перед анализом матча ростеры проверяем ТОЛЬКО по бокс-скору.
17. **Предматчевые injury-отчёты не финальны.**
    - Аткинс (06.08) играла со статусом «Out» — 28:47 минут.
    - Симс (07.08) играла со статусом «Out» — 24:30 минут.
    - Правило: перед ставкой сверять с финальным стартовым составом.
18. Injury-статьи устаревают за недели (июньские «OUT» ≠ статус в августе).
Порядок проверки статуса игрока перед матчем:
  1) НАШ последний бокс-скор (играл ли он вчера/в прошлом матче);
  2) подтверждённые стартовые составы за 30-60 мин до старта;
  3) и только потом — статьи, с проверкой их даты.
Сегодняшний кейс (08.08.2026) : Коллиер «OUT» по старым статьям → 33 минуты 07.08 → в старте 08.08.

## Системные правила (применяются всегда)

### Красные флаги для ставок
- Фаворит -14+ на серии 7+ → НЕ СТАВИМ
- H2H без звёзд → игнорируем
- Команда <10 AST за матч → ИТМ этой команды
- Injury-отчёт «Out» → ждём финальный состав

### Зелёные сигналы для ставок
- Андердог дома + элитная защита + серия побед → ML
- GSV +фора → берём всегда
- WAS в качелях (фора ±4) → берём их сторону
- Худшая атака лиги → ИТМ
- Команда после коллапса -20 → фейд в следующем матче

### Данные, которым НЕ доверяем без сверки
- Бэк-ту-бин (вес всего 10%)
- Memory-ростеры (всегда сверяем по бокс-скору)
- Предматчевые injury-отчёты
- Q4 при мардже >15 очков (garbage time)
